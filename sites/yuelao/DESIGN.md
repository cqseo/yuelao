# 月老站 · 視覺方向（DESIGN.md）

> 一個世界：全站都是同一座廟會夜。首頁不再是冷黑目錄——它就是儀式頁的同一幅夜景（同一張燈籠照片、同一層暖色暗角、同一套朱紅燙金書法）。首頁到搖籤之間不應該有風格接縫：進站第一眼看到的世界，就是搖籤時身處的世界。
>
> 首屏零等待是硬指標：首頁打開立即可用，圖片只在暖色底上漸進載入；儀式頁首屏只預載背景 + 竹筒兩張圖，其餘懶載。

## 令牌（全站同一套，不分頁面）

角色制（參照 Refero 方法：每個令牌都有職責）：

- **底**：墨黑 `--ink #12100E`、墨黑二階 `--ink-2 #1C1915`（廟夜的墨黑與其階調，暖黑不是純黑）；全站底色再加一層暖色徑向底（`radial-gradient(120% 90% at 50% 28%, #503018 0%, #2c1b0e 58%, #1b110a 100%)`），圖未載入時場景也不塌成死黑——這層暖底就是廟會夜本身，不是裝飾。
- **主體**：朱紅 `--red #C0392B` / 深朱紅 `--red-deep #8E2418`（漆器、印章本色與暗階，只給漆器與主行動）
- **強調**：燙金 `--gold #C9A227` / 淺金 `--gold-soft #E6CC7A`（只給關鍵字、印記邊與狀態）
- **紙面**：米紙 `--paper #F3E9D2`（同時是深底上的正文字色）；深底次要文字 `--paper-78 rgba(243,233,210,0.78)`、說明文字 `--paper-62 rgba(243,233,210,0.62)`；金邊 `--gold-55 rgba(201,162,39,0.55)`
- **字體**：Noto Serif TC（正文、標題）+ Ma Shan Zheng（印章、籤頭、豎排書法、**大類名**）；自託管 woff2（`public/fonts/`），不要 Google Fonts 外鏈；`font-display: swap`。**正文就是襯線體**（body 已是 Noto Serif TC）——P5 之前「正文像無襯線」是字太小的錯覺，不是字體問題；修字號與行距，不換字體。
- **字階（P5 定版，有層級）**：豎排書法 display `clamp(52px, 15vw, 68px)`（儀式頁 v-title）/ 英雄簽系名 40px / `h1` 40px（2.5rem，行高 1.2）/ `h2` 28px（1.75rem，行高 1.35）/ 小眉題 14px（字距 0.3em，金色）/ 正文閱讀 16–17px（行高 1.8–2.0，判詞/籤頁/政策頁/首頁章節一律）/ 次要文字 14px（行高 1.7）/ 註腳 12px。舊的 12 / 14 / 17 / 22 / 34 五級作廢，儀式頁內部的 `--t12/14/17/22/34` 是儀式屏的局部刻度（觸控屏寸土寸金，另見下），不與站點字階混用。
- **圓角（P5 定版）**：只剩 **4px 一檔**——膠囊 999px 全站退役（首頁搖一搖、解籤提交、儀式 CTA、長按鍵、感應鍵、精選/即將推出標籤、toast 一律 4px）。進度條軌道（steps、pp-track）是量尺不是按鈕，保留細圓角。觸控目標尺寸不變（CTA 56px、長按鍵 52px），只改形狀，不縮尺寸。
- **按鈕語言（P5：方正 + 印章）**：主行動是朱紅實心方塊 + 一道細內框線（`outline: 1px solid rgba(243,233,210,0.6); outline-offset: -5px`，像印章的邊框），禁用態無內框。卡片一律 4px + 金線邊，不用陰影撐場面。選中大類仍是整塊朱紅（與儀式頁 `.cat-row.sel` 同款）。
- **動效**：入場一律 `--ease-out cubic-bezier(0.22,1,0.36,1)`；彈簧 `--spring`（linear() 曲線）只給有重量的實物（籤筒擺動、籤升起、杯落地），只許一次小幅回彈、快速衰減
- **材質優先於配色**：漆面、紙紋、燭光——不要用 CSS 色塊拼主體物件（竹筒、筊杯、籤、燈籠一律用真實影像素材）；首頁英雄區就是同一張廟會夜照片，不是新畫的漸變。

## P5 視覺第二輪（2026-11-06：對標 kaucim 視覺/版式後修，不改廟會夜方向）

- **頂欄是真導航**：品牌 + 問事總目 + 隱私/條款 + 語言切換。問事總目是唯一已上線的導航連結；姻緣簿、香燈簿、我的（P2/P4 未建）P8 已從頂欄拿掉，不留禁用文字、不做死鏈，等頁面建好再加回來。當前頁加金色下劃線。手機上導航可換行，隱私/條款收進頁尾（頁尾本來就有）。
- **桌面儀式頁兩側不再留黑**：≥1100px 時儀式頁是三欄——左欄「搖籤四步」（靜態步驟說明）、中欄 480px 儀式本體、右欄「這一百支籤」（誠實說明 + 從第一籤看起的連結）。兩欄是安靜的配角（14px、paper-62、細線分隔），不搶中欄的戲；<1100px 兩欄隱藏，390px 驗收不受影響。引擎只認 `.wrap` 內的 `.screen`，加欄不動結構。
- **首頁長卷（問事總目之下）**：三章，不抄 kaucim 的壹–柒編號——「怎麼問」（四步 + 一支真籤的判詞範例）/「這一百支籤」（誠實說明）/「問答」（FAQ，首頁掛 FAQPage schema）。章與章之間 64px（手機 48px）+ 金線分隔；每章先有小眉題（14px 金色字距拉開）再有 28px H2；正文 16px/行高 1.9。**誠實文案鐵律**：一百支籤是本站新寫的，正式籤詩底本待定——不認任何廟宇出處、不寫嗇色園、不寫人數與銷量。
- **判詞卡是結構化答案**：米紙卡內依次是結論（原有處境判詞）→「三天內可以做」（每處境 2 件，3 處境共 3 段）→「七日練習」（每處境 1 段）→ 免費到此為止的提示行（只寫真話：結論、三天可做的事、七日練習都已給，深度解讀是再往下深一層，不寫百分比）。小標題左對齊 + 金色細線，與詩文居中區分開。深讀鎖定區（五項清單 + 信任話術）原封不動留在卡下。
- **籤頁（/sign/:id，P5 程序化）**：同一世界——深底上的米紙籤卡（籤號/吉凶/籤詩/結型），其下三種問法的判詞分段（每段配三天/七日塊），再下是前後籤與同籤等連結（細線分隔行）。H1 40px，籤詩 22px 粗體，正文 16px/1.9。簡體籤文未審時回落繁體原文 + 同款提示（見 sticks-locale.ts）。
- **SEO/GEO 令牌**：sitemap 是索引（/sitemap.xml）+ 兩層（/sitemap-pages.xml 核心頁、/sitemap-signs.xml 100 支 × 2 語言）；llms.txt 一檔雙語（繁體版 + 簡體版，handler 按 /hk/ 前綴分流）；404 頁給 llms.txt 連結；頁尾給 llms.txt 連結。canonical 一律走 site.config.ts 的 url（現仍是 yuelao.example.com 佔位，等品牌/域名定）。

## P7 技術輪（2026-11-06：語言改 kaucim 式同路徑切換 + 搖籤前選問題 + 第一批基礎修復）

- **語言是同路徑切換，不是路徑制**：繁/簡是同一地址下的「字形」切換（抄 kaucim：語種靠路徑、繁簡不改路徑）。頂欄切換是兩個按鈕，點一下寫 `PARAGLIDE_LOCALE` cookie（path=/、約 400 天）再整頁重載；伺服器中間件讀 cookie 做 SSR，客戶端讀同一個 cookie——兩邊同一信號，不會水合錯位。舊 `/hk/*` 一律 301 到去掉前綴的同一路徑。sitemap、canonical、llms.txt 都是單棵樹（100 支籤頁 + 6 核心頁 = 106 個 URL）；**沒有獨立簡體網址，就沒有指向簡體的 hreflang**（hreflang 指向同一 URL 是錯的，不加）。
- **首頁 H1**：英雄區簽系名就是 H1，文字是「線上月老求籤」（不是裝飾字，40px 書法，同款式）。
- **搖籤前選問題**：準備頁（scr-prep）上加一排問題選擇——每類 3–4 個預設問題 +「默念其他問題」（不選 = 現在的默念行為）。不打字。選了的問題帶到判詞卡，顯示「你問的是：……」；判詞正文不變（預先寫好的，不謊稱是為這個問題現寫的）。
- **手機問事總目**：≤640px 時四個大類是乾淨的 2×2 格子（之前是 flex 換行，排得不齊），說明文字隱藏、選中仍是整塊朱紅。
- **安全標頭與快取**：HTML 由 Worker 回應時帶 CSP（script/style 允許 inline——TanStack Start 水合要 inline script；其餘只許 self）+ nosniff + Referrer-Policy + frame-ancestors none；帶雜湊的 /assets/* 用 `_headers` 給一年快取，HTML 仍每次驗證。

## P8 小修（2026-11-06：用戶三點反饋）

- **英雄 CTA 不換行**：`.ask-shake` 一律 `white-space: nowrap`；≤640px 字號 0.875rem、左右 padding 收窄，`.ask-system` 允許整行換行（按鈕整顆掉到下一行，不在字中間斷開）。儀式頁 `.cta` 同樣 nowrap；btn-row 兩顆按鈕是 grid，窄屏若擠不下就整顆換行，不斷字。
- **頂欄沒有假按鈕**：姻緣簿 / 香燈簿 / 我的（P2/P4 未建）直接從頂欄拿掉，不留禁用文字；只剩問事總目（唯一上線連結）+ 隱私/條款 + 繁/簡切換。等頁面建好再加回來，不要先佔位。
- **結型用真照片，不用畫的**：三種結各一張實拍圖（`public/ritual/knot-tongxin.webp` / `knot-huo.webp` / `knot-hua.webp`，生成圖裁到繩結 + 小邊距、邊緣羽化透明、WebP，單張 ≤60KB），按籤的結型（同心結/活結/滑結）取圖，判詞卡與籤頁共用同一份對照。顯示高度固定（判詞卡 180px、籤頁 140px），寬度自適應、置中；結名文字（同心結/活結/滑結）留在圖下不動。
- **P8-fix：結圖真去背、不再 multiply**：P8 第一版把紅色遮罩高斯模糊 18px，結果沒有任何像素保持不透明（0.01%），結在卡上像一層淡淡的鬼影；又因 `multiply` 壓暗，紅絲越發灰暗。修法：`tools/knot-webp.py` 改真去背——紅繩本體硬 alpha（僅 1–2px 羽化）、暗紅（R 低到 55）與亮邊（R-G ~37）都算繩、繩內小白點/黑點填成本地繩色、繩外只留一層淡接觸陰影；三張去背後都不再用 `multiply`，紅色直接透出，紙紋從結的孔洞裡自然透出來。判詞卡結圖 112px → 180px、籤頁 96px → 140px，結是卡的視覺主角、不是縮圖。

## P9 深度解讀真正可買（2026-11-08：鎖定區接上結帳）

- **鎖定區不換結構，只換狀態**：`.deep-lock` 原本的五項清單 + 三句信任話術整塊不動；「即將推出」標籤改成：未登入時顯示「登入解鎖」，已登入時整塊拿掉（不是永遠顯示）。主 CTA 文案由「深度解讀 {price} · 即將推出」改成「解鎖深度解讀 {price}」，disabled 態退役。
- **方案選擇抄 `.q-pick`，不新開一套元件**：單次解鎖 / 問事包 3 次 / 問事包 8 次三個一排（`.tier-row`，三欄 grid），每個是 `.tier-pick`——金線邊、4px 圓角、深底半透明，選中時整塊填朱紅（與 `.cat-row.sel`、`.q-pick.sel` 同一邏輯，不是另畫一套高亮）。價錢來自 `site.config.ts` 的單一 `price`（不再分港幣/台幣——全站一個貨幣，Stripe Checkout 自己對買家的所在地做顯示幣別換算，前端不用知道買家在哪）。
- **登入是就地展開，不是另開頁面**：沒有帳號系統頁、沒有彈窗——點 CTA 時，未登入就在鎖定區內多展開一步（email 輸入 → 驗證碼輸入），驗證通過後直接接著原本要做的事（呼叫 `/api/checkout` 並跳轉），不用使用者再按一次「購買」。輸入框只有底線（`.auth-input`，無邊框色塊），不引入任何表單元件庫。
- **錢只走 Stripe 的頁面**：前端拿到 `/api/checkout` 回的 `url` 就整頁跳轉過去，不自己畫信用卡輸入框、不接觸卡號。
- **錯誤只給一句話**：`.auth-error` 一行金色字，不堆疊多個提示框；重試路徑就是再按一次同一顆按鈕。

## 頁面（同一世界，不同房間）

- **首頁（問事總目）**：版式抄 kaucim（左欄編號大類、右欄工具列表、免/精選標記），**視覺抄儀式頁**。頂部是一幅廟會夜英雄區：同一張 `temple-fair.jpg` 全幅打底 + 同一層 scrim（上透下暗，底部沉進頁面暖底），簽系名、搖一搖主行動、直接解簽、其他問法都壓在這幅夜景上。大類名用 Ma Shan Zheng 書法金字（與儀式頁 `.cat-row .word` 同款）；選中類別整塊填朱紅（與儀式頁 `.cat-row.sel` 同款），不是只描一條左線。入口卡片暖底 + 金線邊，hover 才亮金邊。直接解簽的結果是一支籤——給它判詞卡同款米紙（`paper.jpg` + 朱紅內框 + 深色字），不是深底文字。頁頭頁尾同一套暖底：品牌名書法金字，語言切換只是文字（不做藥丸，避免與搖一搖 CTA 認錯）。
- **儀式頁**：暖金廟會夜背景（全幅）；竹筒、筊杯、主籤用原型已修好的實物圖；判詞卡豎版米紙，結型實拍圖（P8）+ 「月老已批」印（蓋印動畫 0.26s）；深度解讀為鎖定態（五項解鎖清單 + 三句信任話術 + 「即將推出」按鈕，不接支付）。儀式頁不掛站點頭尾（全幅沉浸），只留四步指示點。
- **政策頁 / 404**：輕量沿用同一世界——暖底、書法品牌、金線分隔、標題燙金；不另起一套冷色模板。
- **移動端優先**：390px 驗收；按鈕最小 52px 高，單手可操作；安全區 env(safe-area-inset-*)。英雄區在手機上內容置底，照片不裁掉燈籠。

## 儀式鐵律（原型已修好，一個字別改）

- 搖籤前筒口不露任何單支主籤，主籤搖後才出現，籤號只在掉籤落定那一刻揭示。
- 掉籤與筊杯落定後一律凍結不動，重擲才從落點姿態起步。**掉落橫躺的籤支，籤號字要反向轉回橫排正著讀**（落定幀按最終角度反補，見 physics.ts flyStick）。
- 筊杯面標記金色嵌線（直線 = 平面、弧線 = 凸面）加小字說明；笑筊兩凸面、陰筊兩平面。
- 同會話不重複出籤（100 支抽完才重置）。
- 物理量放 ref、逐幀寫 DOM，絕不每幀 setState；React state 只管屏切換、籤/處境、擲筊結果、按鈕顯隱。
- **文案與行為必須一致**：能量鬆開會回落（13%/秒），文案就寫回落，不寫「停」；陰筊「明天再來」是結束，回網站首頁，不回選類頁。
- **Toast 是短暫確認，不是常駐條**：3 秒自動消失、點按立即消失、切屏時清掉；定位永遠在底部按鈕行之上，不得遮住任何可點按鈕。
- **感應文案與裝置無關**：不寫「這支手機」——桌面也是裝置，寫「此裝置」。

## 不要做的事

- 不要 AI 預設風（居中標題 + 柔和漸變 + 色塊卡片）
- 不要重 3D、不要首屏等待畫面
- 不要 shadcn 式組件庫（會壓平題材獨特性）
- 不要機器轉換的簡體籤文未經人審就上線：簡體籤文缺已審譯本時回落繁體原文（見 `src/ritual/sticks-locale.ts`）
- 不要首頁與儀式頁各用一套視覺語言：新增頁面先問「它在廟會夜裡長什麼樣」，不要另起冷色模板
