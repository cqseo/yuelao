# 月老 V3 · 留存、對話與留白視覺（2026-11-09）

## 產品方向

從一次性求籤頁升級為可每日回訪的情感文化產品。參考競品 kaucim.ai 的「免費試聊、每日簽到及額度型聊天」留存模型，但不照搬其產品文字、視覺素材或付費設計。本站保留月老紅線和篆印的東方意象，以大留白、暖紙底色、窄朱紅、宋體編排為視覺基調。

## 本階段實作

**首頁**：新增「有些心事，慢慢說。」的輕量編輯式 Hero；「與月老聊聊」「每日心箋」成為首頁主入口。原始求籤／測驗／百支籤文完整保留，原 Hero 順移到下方，避免改壞已有核心路徑。桌面與手機版皆使用相同設計語言。

**/chat**：完成無需登入、無費用、可自由輸入、多輪追問、情境建議、清空對話的「月老心語」**引導式對話 MVP**。具備失戀、信任困惑、暗戀、溝通、孤獨、自我邊界、危險／傷害等情境判斷。對傷害／危險不做玄學預測，優先建議可信賴的人和當地緊急／專業支援。**這不是即時 LLM／真人對話**，不應用「智能 AI」字樣誤導客戶。聊天原文只在當前 React 頁面記憶體，不傳伺服器，也不保存到 LocalStorage。

**/daily**：免費每日心箋，依當地日期和使用者選擇的主題（緣分、溝通、心境、行動）穩定展示一則文化反思句、一段建議與一項可行小行動。內容不是個人命理預測，頁面明確告知。每日簽到以瀏覽器 `localStorage` 紀錄最近 45 個日期與連續日數，同一天不重複領取；與金錢、支付積分或帳戶權益沒有關聯。這一版不跨裝置，不打卡付費銅錢，不要求付費或增加 Supabase 雲成本。

**可訪問性與 SEO**：維持繁體預設，支援簡體；文字對比、鍵盤 focus、語意標題、清晰的標籤、手機端 390px 與桌面 1440px；新的 URL 進入 sitemap，獨立 canonical，隱私政策新增本機簽到及對話資料說明。更新自託管中文子集字體，確認新文案不缺字。

## 驗收

- `pnpm lint`：Biome 無錯誤／警告；`pnpm check`：TS、Vite build、site check 通過（原本既有 supportEmail 佔位及 CSS sourcemap 警告與本次無關）。
- `tsx tools/test-retention.ts`：當地日期、同日防重複、連續日與中斷重置、錯誤資料、繁簡體每日心箋、情境對話安全回覆均通過。
- Chromium 真實瀏覽器：首頁、新 Hero 導航；每日主題切換、簽到成功後重新載入不重複、聊天提示問題→自由輸入→多輪回覆→清空；390px、1440px 無橫向溢出／ JS errors。遠端預覽與正式站上線後需重複遠端檢查。

## 仍未完成／不可誤導

1. **即時 AI Chat**：本階段仍為不連模型的免費引導式版本。要真正達到 kaucim.ai 的 LLM Chat 體驗，須設計模型調用、用戶明確同意發送內容、匿名每日額度防濫用、成本硬上限、日誌／保留策略、失敗降級；**不能在未設定上限時直接開放付費 Workers AI/OpenAI**。
2. **跨裝置簽到／帳戶銅錢**：尚未做，因生產 Auth 尚未驗收，避免變成可刷的充值權益。任何付費抵扣只能由後端可靠賬本發放。
3. **留存效果**：D1、D7、D30 回訪、對話開始率、簽到次數和 3 日連簽率，應在透明告知的分析方案上線後實測。不可宣稱「一定能留存」。
4. **支付**：Stripe live charge 仍關閉；不要把這三個免費功能當作付費全鏈路已上線。
5. **客服電郵**：`supportEmail` 原本佔位未設定；收費前必須修正。

## 建議迭代順序

真實 AI 對話（限制免費次數與每日總成本）→ 帳戶跨裝置簽到 → 7 日陪伴任務／紀念書籤（非支付貨幣）→ 安全試付與高級解讀 → 以回訪數據迭代。
