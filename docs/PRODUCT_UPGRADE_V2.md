# 月老 2.0｜情感與東方玄學產品升級方案

> 2026-11-08；開發分支：`feat/emotional-tests-v2`。本文是產品路線及驗收標準，不代表後續階段已實作。

## 1. 戰略定位

- 品牌方向：「月老 · AI 情感與姻緣平台」；先服務曖昧、單身、分手／復合與信任困擾。
- 價值主張：免費自我整理（心理學知識須準確）＋傳統月老文化體驗（清楚標為文化／娛樂）＋未來獨立計價的 AI 個性化分析。
- 拒絕：未經驗證的「出軌機率」「復合成功率」、臨床診斷、替第三方讀心、恐嚇式付費墻。
- 初期主市場：繁體中文使用者（臺灣／香港）；簡體中文作可選語言。語言、地區與結帳貨幣日後要解耦。

## 3. V2-1 交付範圍（本開發分支）

- 5 個工具共用一個題庫與測驗引擎，單個測驗 8 題、各 3 個頻率選項。
- 免費完整結果，包含回覆摘要、可行建議和限制說明；零登入要求、零付費牆。
- 繁體／簡體人工撰寫雙文案；同 URL cookie 切換，保留現有路由策略。
- 原生 radio 選項、進度條、上一題／下一題、重測及分享測驗連結；支援鍵盤。
- 不持久化答案，不存 localStorage；分享時不含答案與結果。
- 匿名事件：`test_started`、`test_completed`，僅上報測驗 slug 與完成動作；不傳答案、分段結果及可識別的回答資訊。
- 全部 6 個 URL 登記 sitemap；首頁及主導航加入可用連結。
- 8 題的分段門檻是編輯設計，不是統計學／臨床心理學驗證，UI 絕不可當作測量真相或可能性百分比。

### 不包含

- AI API、會員、付費、個人檔案、真實用戶行為資料、市場流量評估、實際正式部署。
- 公開測驗不收集出生資料、另一半照片、名字或聯絡方式。

## 4. V2 UI/UX

遵循 `sites/yuelao/DESIGN.md` 既有設計語言：
- 保留原儀式頁的廟會夜、書法、朱紅／燙金、米紙判詞。
- 在測驗中心沿用夜色背景和金線邊；作答紙面使用米紙、深棕字，提高長文閱讀性。
- 全站共用 Noto Serif TC 字體、4px 方正邊角及印章式主按鈕，沒有 shadcn 或冷色 SaaS 風格。
- 手機 390px 優先：單欄卡片、>=52px 互動高度、無橫向溢出、鍵盤焦點可見、降低動效偏好受尊重。
- 目標流程：首頁 → 測驗中心／直接進工具 → 8 題 → 免費結果 → 其他測驗／月老求籤。

## 5. 後續路線（優先順序）

**V2-2（P0 支付/AI 商業閉環）**
1. 使用者自願輸入自己的情境 → AI 產生個性化分析；資料最小化、敏感資訊告知與刪除機制。
2. 價格實驗：單次解讀 HK$18；專項分析 HK$38。價格是待驗證假設，不是現行上架承諾。
3. Supabase Auth OTP、保存已購報告、Stripe Checkout、Webhook 簽名/冪等/退款/拒付測試。
4. 解開「語言=付款貨幣」耦合；購買與履約需要清晰的產品標識。
5. 不誇大 AI 與傳統籤文的關聯； AI 生成內容要清楚標示。

**V2-3（留存）**
1. 姻緣簿，手動保存結果與關係進展；用戶可刪除並自由退出。
2. 第 3、7 天自願回訪；通知預設不開啟、控制頻率，避免鼓勵過度測試。
3. 合盤與命理採透明的傳統計算規則，清楚區分文化詮釋與現實建議。

**V2-4（增長）**
1. 工具頁長尾 SEO：解決一個問題、有實質內容、避免批量僅換關鍵詞。
2. 以分享連結＋無隱私洩漏的卡片做社交傳播。
3. 根據 GSC、完成率、來源、匿名轉化與採訪再決定擴充 10–20 個工具。
4. 流量與付款對照不同地區；先驗證留存／退款率，再上會員。

## 6. 完成驗收

- `pnpm --filter ./sites/yuelao check` 及 lint 通過。
- /tests、5 個子頁對無效 slug 返回 404；首頁/頂欄/sitemap 路由可用。
- 5 項各能完整完成測驗，無答案不能跳下一步，重測會清空狀態。
- 不同回答導出不同結果；結果免費、不得假稱「出軌概率」。
- 繁簡切換無 hydration mismatch；手機 390/768、桌面 1440 上視覺和鍵盤均正常。
- 不上報答案、分享不含答案；敏感情境有支援提醒。
- 缺失的二進制素材、字型子集和正式支援郵箱在生產部署前補齊；完成 e2e 後才合併。
- 生產部署與支付另需明確發佈確認。
