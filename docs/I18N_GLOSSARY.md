# 多語言詞彙表（2026-11-14）

翻譯不是逐字換：外國讀者不認識月老、筊杯、判詞。這份表記下每種語言對這些詞的固定說法，之後新增或修改譯文都照這裡，免得同一個東西有三種叫法。

原則：

1. **先讓人看懂是什麼，再保留原名。** 首頁與分享標題第一次提到月老時，補一句他是誰（牽紅線的姻緣神）。
2. **用當地已有的說法。** 泰國本來就拜月老、擲筊，有現成的詞；日本的台灣旅遊書也有固定寫法。
3. **避開同音歧義。** 漢字直接音譯到韓文常撞到別的詞（見下表「不要用」）。

## 不要用

| 語言 | 不要用 | 為什麼 |
|---|---|---|
| 한국어 | 성교（聖筊的音譯） | 讀起來是「性交」 |
| 한국어 | 교배（筊杯的音譯） | 讀起來是「交配」 |
| 한국어 | 판사（判詞的音譯） | 讀起來是「法官」 |
| 한국어 | 본전（本殿的音譯） | 常用義是「本錢」 |
| ไทย | คำตัดสิน（判詞） | 是法院的「判決」 |
| ไทย | โป้ย | 泰國通行的寫法是 ปวย |
| English | Mine（我的） | 讀成「礦」或「我的東西」，導航上不知所指 |
